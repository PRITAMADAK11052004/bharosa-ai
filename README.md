# Bharosa AI (CogniMem)

**Personal Multimodal AI That Thinks Offline**

A fully **offline**, privacy-first multimodal AI assistant that turns your smartphone into a true personal cognitive companion.

Using advanced **Retrieval-Augmented Generation (RAG)** and semantic memory, it helps you search, recall, and reason over all your personal files — PDFs, images, notes, lectures, screenshots, and audio — without any cloud dependency.

---

### ✨ Key Features
- **100% Offline & Private** — Nothing leaves your device
- Multimodal support (Text, Image, Audio, Video)
- Intelligent Cognitive Reasoning with quantized Llama-3
- Hybrid Vector + Metadata Memory Architecture
- Semantic Chunking & Cross-Modal Retrieval
- Optimized for mobile edge devices

### 🎯 Why Bharosa AI?
Modern users store thousands of documents but struggle to recall and reason over them. Bharosa AI solves information overload while keeping your data completely private.

**Built for**: Students, Researchers, Knowledge Workers, and Lifelong Learners.

---

### 🛠️ Tech Stack
- **Embedding**: MiniLM (INT8 Quantized)
- **LLM**: Qwen (Quantized)
- **Vision**: MobileCLIP
- **Vector DB**: LanceDB
- **Inference**: NNAPI (Android) / CoreML (iOS)
- **OCR**: PaddleOCR
- **Speech**: Faster-Whisper Tiny

**Fully Offline • Edge Optimized • Zero Cloud Dependencies**
